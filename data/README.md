# Исходные данные

Скачайте **Brazilian E-Commerce Public Dataset by Olist** с Kaggle:

<https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce>

Скопируйте из архива в эту папку три CSV:

- `olist_orders_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_customers_dataset.csv`

После копирования структура должна выглядеть так:

```text
data/
├── README.md
└── raw/
    ├── olist_orders_dataset.csv
    ├── olist_order_reviews_dataset.csv
    └── olist_customers_dataset.csv
```

Архив набора не хранится в этом репозитории. Страница Kaggle указывает условия использования исходных данных; перед повторным распространением самих данных проверьте их лицензию и ограничения.
